📱 Petunjuk Setup SEB di iPad Siswa
Klik untuk tampilkan / sembunyikan langkah-langkah instalasi
▼
  1. Install SEB di iPad: Download Safe Exam Browser dari App Store (gratis).
  2. Generate Barcode SEB: Klik 📷 Generate Barcode SEB — QR berlaku permanen, cukup print sekali.
  3. Siswa scan QR dari aplikasi SEB: Buka Safe Exam Browser di iPad lalu gunakan fitur scan QR. Ganti password SEB kapan saja untuk mengontrol akses keluar siswa.
  4. Verifikasi berhasil: Setelah SEB terbuka, halaman akan langsung menuju login Moodle. Address bar dan toolbar tersembunyi. Nama device akan muncul di tabel "Pantau Download Config" di bawah.
  5. Untuk ujian berikutnya: Guru wajib generate QR baru sesuai tanggal ujian berikutnya.
⚠️ Penting: Link SEB tanpa QR bertanggal akan ditolak sistem. Gunakan QR resmi dari dashboard untuk setiap hari ujian.
📲 Petunjuk Instalasi Dosman Exam (Android)
Panduan lengkap install APK untuk siswa — termasuk nonaktifkan Play Protect
▼
  1. Nonaktifkan Play Protect: Buka Play Store → Profil → Play Protect → nonaktifkan pemindaian.
  2. Izinkan Sumber Tidak Dikenal: Buka Pengaturan → Keamanan → aktifkan "Instal aplikasi tidak dikenal" untuk browser/File Manager.
  3. Install APK: Download dan buka file APK, tap Instal. Jika muncul peringatan Play Protect, tap Tetap Instal.
  4. Izinkan DND: Saat pertama buka aplikasi, izinkan akses Do Not Disturb agar aplikasi dapat memblokir notifikasi selama ujian.
  5. Login: Masukkan username dan password yang diberikan guru.
  6. Pinning Aplikasi: Saat muncul notifikasi "Aplikasi disematkan", tap Oke untuk mengunci layar ke mode ujian.
⚠️ Penting: Jangan paksa tutup aplikasi selama ujian — akun akan otomatis tersuspend dan harus dibuka oleh pengawas.
